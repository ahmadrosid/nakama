Open **Control center → Integrations** to manage settings that span agents or the whole installation.

## Available sections

- [Notifications](/telegram/notifications): send agent events to a Telegram topic, a Discord channel, or a WhatsApp contact
- [Composio](/composio): connect SaaS toolkits with per-user OAuth and assign them to agents
- **Coding agents**: choose Nakama provider passthrough (default) or harness login on this server. See [Coding agent](/coding-agent#provider-passthrough)
- **Context savings**: configure token optimization and review its savings. See [Token optimiser](/token-optimiser)
- [Error tracking](/error-tracking): send this instance's own crashes to your Sentry, GlitchTip, Bugsink, or Rustrak project

Channel credentials and bridge workers belong to one agent. Open **Agent → your agent → Channels**, then choose [Telegram](/telegram), [WhatsApp](/whatsapp), [Discord](/discord), or [Slack](/slack). MCP servers live under **Control center → Agent tools → MCP**. See [MCP servers](/mcp).
