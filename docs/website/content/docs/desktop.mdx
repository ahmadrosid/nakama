title: Desktop
description: Use Nakama's web app in a desktop window.
---

Nakama Desktop opens the same Nakama app you use in your browser. Conversations, agents, uploads, and configuration all use the existing web interface.

The desktop app is a development preview for Apple Silicon Macs running macOS 26. There is no signed public download yet.

## Connect

1. Keep your Nakama server running.
2. Open Nakama Desktop.
3. Sign in using the normal web sign-in form.

The default connection is your local Nakama server. Desktop has its own saved browser session, so sign in once even if you already use Nakama in a browser or used the earlier GPUIX preview. Your agents and conversations stay on the server.

## Use Nakama

Chat, select agents, upload files, and configure your organization exactly as you do on the web. Your permissions are the same. Links to other websites open in your normal browser.

If the server is unavailable, start it and select **Retry**. Closing the desktop app closes its connection; the server continues running independently.
