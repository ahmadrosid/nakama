---
title: Desktop
description: Run Nakama locally in a desktop app.
---

Nakama Desktop includes its own server and the existing web interface. Open the app to start everything locally; no separate server or Docker installation is needed.

The desktop app is a development preview for Apple Silicon Macs running macOS 26. There is no signed public download yet.

## Get started

1. Open Nakama Desktop.
2. Create your account and organization in the setup wizard.
3. Configure a model provider and start chatting.

Cloud model providers still need an internet connection and credentials. Optional tools may need programs such as Python or a coding CLI installed on your computer.

## Your data

Desktop keeps its own local accounts, conversations, and configuration. Existing web-server data is not imported automatically. Your data remains when you close or update the app.

The local server accepts connections only from your computer. Quitting the desktop app stops its server, automations, and channel workers. Keep the app open for background tasks to run.

## Use Nakama

Chat, select agents, upload files, and configure your organization using the same web interface. Links to other websites open in your normal browser. Microphone, camera, and notification permissions are disabled in this preview.

If the local server stops unexpectedly, reopen Nakama to restart it.

## Updates

Signed desktop releases check for updates when opened and every six hours. Updates download in the background. Choose **Restart now** when prompted to install, or **Later** to continue working.

Restarting stops running local tasks and preserves your saved data. Quitting normally does not install the update. If you use an unsigned development preview, install the first signed release manually to enable automatic updates.
