---
title: "Agent groups"
description: "Put several agents in one chat, give them one brief, and let them hand work to each other."
---

## Why

Some work needs more than one agent. A researcher finds facts. A writer turns them into a draft. Without a group, you copy the answer from one chat to the next.

## Value

- One chat holds several agents. They all read the same brief.
- You choose who answers. Mention one agent, or all of them.
- An agent can pass the work to another agent. You can stop it at any time.
- You can open a private thread with one agent on one of its messages.

## How

Admins and members can use groups. Viewers cannot.

### Create a group

1. Open **Groups** and select **New group**.
2. Add a name. You can add a photo.
3. Add 2 to 12 agents.
4. Write a **Brief**: what the group is for. Every agent reads it.
5. Select **Create group**.

To change a group later, open its menu in **Groups** and select **Edit group**. In an open group, **Add agent** opens the same dialog.

### Talk to the agents

Each agent has an `@handle` that comes from its name. Type `@` in the composer to pick one.

| You write | Who answers |
|---|---|
| `@writer draft the intro` | Only the writer |
| `@all introduce yourselves` | Every agent, one after the other |

If an agent mentions another agent in its reply, that agent answers next. The chain stops after a few hand-offs. Select **Stop** to end it at once.

Agents reply in short chat messages. Ask for more detail when you need it.

### Chats and threads

- **New chat** starts a fresh chat in the same group. The brief and the agents stay the same.
- Open a thread on an agent's message to talk with that agent alone. The other agents do not see the thread.

### Find a group fast

Press **Cmd+K** (**Ctrl+K** on Windows and Linux) and type the group name.

### Create a group from chat

Ask Super Nakama to create a group. It asks you to confirm the name, the agents and the brief first.
