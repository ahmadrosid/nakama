---
title: "Workflows"
description: "Install the official Workflows plugin to run repeatable recipes with verified step results."
---

Workflows run a saved recipe when you ask. Each step records its result, and the final summary uses those results. Use automations for scheduled prompts.

## Install

1. Open **System → Plugins** as an organization admin.
2. Under **Official plugins**, click **Install** on **Workflows**.
3. Open **Workflows** from the sidebar's **Plugins** group.

Installation enables the plugin for your active organization and imports its existing workflows and run history once. The original data stays intact. You do not need to enter a package name or version.

## Create and run

1. Click **New workflow**, enter a name, and choose an agent.
2. Add and order the steps, then enter the final summary instructions.
3. Click **Save**, then **Run**.

| Step | What it does |
| --- | --- |
| Tool | Calls a tool assigned to the selected agent |
| Compare | Checks two values for equality, closeness, or containment |
| Assert | Checks a value at a result path |
| Template | Builds text from earlier results |
| Summarize | Writes a final summary from the recorded results, without calling tools |

Use `{{input.range}}` to reference run input and `{{steps.fetch.value}}` to reference an earlier step. Missing referenced data or a failed check stops the recipe before later steps run. Explicit null values remain allowed. Templates only substitute text; extraction or analysis before a database write needs a tool that performs that work. The summary must be the final step.

Open the **Runs** tab and expand a run to see its output and step receipts. The **Data** tab at the top of the editor browses tables used by the agent's SQLite tool; these stay separate from recipe and run storage.

## Use from chat

Assign the plugin's tools and **create-workflow** skill to a profile in **System → Profiles**. Then ask that agent to create, update, list, or run a workflow. The plugin page works immediately after installation.

To schedule a workflow, ask Super Bot to create an automation that runs it, including the workflow name and ID. Choose an agent with the plugin’s workflow tools assigned for the automation.

## Manage access

Organization admins install, enable, disable, and uninstall the plugin. Members can use enabled workflows. Viewers cannot open plugin pages or invoke their actions. Members cannot run workflows as Super Bot.

Disable stops new calls and drains active runs. Uninstall keeps the plugin's data until an admin explicitly deletes retained data.
